# เพิ่ม/แก้ธีมสี

ธีมเป็นการแก้ **หลายไฟล์ที่ต้องตรงกัน** ไม่ใช่แก้ CSS ที่เดียว ทำไม่ครบแล้วจะเพี้ยนแบบเงียบ ๆ

## แก้ให้ครบทั้งสี่จุด

1. **[src/lib/theme.ts](../../../src/lib/theme.ts)** — เพิ่มเข้า `THEMES`
   (`name`, `label` ไทย, `dot` สีตัวอย่างบนปุ่มสลับ ต้องเป็น hex 6 หลัก)
2. **[src/app/globals.css](../../../src/app/globals.css)** — เพิ่มบล็อก `[data-theme="ชื่อ"]`
   ที่กำหนด **ตัวแปรดิบให้ครบทุกตัว**
3. `resolveTheme()` กับ `data-theme` บน `<html>` ทำงานอัตโนมัติ ไม่ต้องแก้
4. รันเทสต์ธีมและ contrast

## กฎของ globals.css ที่พลาดง่าย

- **ค่าดิบต้องอยู่ในบล็อกของธีมเท่านั้น** บล็อก `:root` ท้ายไฟล์เป็นค่า *ที่คำนวณจาก* ตัวแปรธีม
  (`--primary: var(--brand-500)`) ถ้าเผลอใส่ `--brand-*` ลงไปที่นั้น จะทับทุกธีมพร้อมกัน
- **ต้องเป็น hex 6 หลัก** — `tests/contrast.test.ts` อ่านด้วย regex `#[0-9a-fA-F]{6}`
  ใช้ `oklch()`, `rgb()` หรือ `#fff` ย่อ จะทำให้เทสต์ throw "ไม่พบตัวแปร"
- **ห้ามมีปีกกาซ้อนในบล็อกธีม** เทสต์ตัดบล็อกด้วยการหา `}` ตัวแรกหลัง selector
- ธีมชมพูเป็น `:root, [data-theme="pink"]` (เป็นค่าเริ่มต้นด้วย) ธีมอื่นเป็น selector เดี่ยว

## ตัวแปรที่ต้องมีครบ

`--brand-50…900` · `--background` · `--cream` · `--ink` · `--ink-soft`
`--accent-warm` · `--accent-cool` · `--accent-fresh`
`--cta-from` · `--cta-to` · `--cta-ink` · `--cta-shadow`
`--mark-from` · `--mark-to` · `--mark-ink`
`--macro-protein` · `--macro-carbs` · `--macro-fat`

> `tests/theme.test.ts` กับ `tests/contrast.test.ts` มีลิสต์ที่ต้องการ **ไม่เหมือนกัน**
> ธีมใหม่ต้องผ่านทั้งสองไฟล์ ให้ยึดลิสต์ข้างบนซึ่งเป็นยูเนียนของทั้งคู่

## เกณฑ์ contrast ที่บังคับไว้

| จุด | เกณฑ์ |
|---|---|
| ปุ่มหลัก (`cta-ink` บน `cta-from` **และ** `cta-to`) | ≥ 4.5:1 ทั้งสองปลาย |
| ปุ่ม disabled (`brand-800` บน `brand-100`) | ≥ 4.5:1 |
| ชิปที่เลือก (`brand-800` บน `brand-200`) | ≥ 4.5:1 |
| `ink` และ `ink-soft` บน `background` | ≥ 4.5:1 |
| `brand-700/800` บนขาว | ≥ 4.5:1 |
| `brand-600` บนขาว | ≥ 3:1 (ตัวเลขใหญ่เท่านั้น) |
| สีมาโครบนขาว | ≥ 3:1 |
| โลโก้ (`mark-ink` บน `mark-*`) | > 1.8 (กราฟิกตกแต่ง ได้ข้อยกเว้น) |

**บทเรียนจากบั๊กจริงสองรอบ**

- ปุ่มหลักใช้ **ไล่สีพาสเทล + ตัวอักษรเข้ม** ไม่ใช่สีสด + ตัวอักษรขาว
  (ขาวบนชมพู/ฟ้าอ่อนได้แค่ ~2.2:1)
- ตอน disabled ต้องสลับ **สีตัวอักษร** ด้วย ไม่ใช่เปลี่ยนแค่พื้น (เคยเหลือ 1.3:1)
- `--mark-*` แยกจาก `--cta-*` เพื่อให้โลโก้คงสีสดได้ ขณะที่ปุ่มต้องอ่านชัด

## ที่ธีมยังไปไม่ถึง

`layout.tsx` ตั้ง `themeColor` เป็นค่าคงที่ สีแถบบนของเบราว์เซอร์จึงไม่เปลี่ยนตามธีม
ถ้าจะแก้ ต้องย้ายไปใช้ `generateViewport()` ที่อ่าน cookie

## ตรวจงาน

```bash
bun test tests/theme.test.ts tests/contrast.test.ts
bun run verify
```

เปลี่ยนสีแล้ว **ยืนยันด้วยตาไม่ได้จาก terminal** — บอกผู้ใช้ให้เปิดดูจริง
